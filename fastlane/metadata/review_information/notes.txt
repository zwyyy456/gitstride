GitStride for macOS is a native workspace for GitHub Projects. It requires macOS 14 or later and a GitHub.com account. Use the dedicated review account supplied in the App Review sign-in fields. No new account or Project needs to be created.

SIGN IN
1. Open GitStride, then Settings > GitHub > Account > Log In to GitHub.
2. Copy the device code shown by the app and open GitHub's device activation page as prompted. Sign in with the supplied review account, enter the device code, and approve the requested GitHub permissions. If your browser is already signed into another GitHub account, use a separate browser profile for the review account.
3. Return to GitStride and allow the project list to load. The App Store build uses OAuth Device Flow; GitHub CLI is not required.

CORE REVIEW STEPS
1. In the workspace sidebar, select the personal owner zwyyy000 and Project gitstride-acceptance. If using the menu bar popover, choose Open Kanban Board to open the workspace.
2. Select Board and find Issue #1 in Done. Clear any active search or filters if needed. Switch to Table to view the same item as a row.
3. Open the item's context menu and choose Show Details to inspect its title and linked GitHub issue. Choose Open in Browser to compare it with GitHub.
4. In Board, use the item's context menu > Move To > In Progress. The item should move to that status. Reload the Project page in GitHub to confirm the Status change was saved. Move it back to Done after testing. Project Status is separate from the issue's Open/Closed state.
5. Search for gitstride-acceptance in the project view to find the sample item, then clear the search.

OPTIONAL PULL REQUEST AUTOMATION
Settings includes Pull Request Automation and a Set Up Automation flow with separate GitHub authorization. It is not needed for the core review steps above. The sample issue has an already-merged PR #2 for inspecting its relationship; it will not generate a new PR event. Testing new automation events requires completing that separate setup and creating a new linked pull request in the sample repository.
