GitStride helps you organize projects, track issues, and follow review requests in one workspace. Check your projects quickly from the menu bar, or use the main window to focus on the work ahead.

• Organize personal and organization projects in Board or Table view.
• See assigned work and review requests across projects in My Work.
• Search by title, issue number, or assignee. Create and edit issues without switching to a browser.
• Choose the fields and filters that matter to you. Display preferences are saved on your device.
• Get optional notifications for status and assignment changes, upcoming deadlines, and overdue items while GitStride is running.
• Optionally connect a separate pull request automation service to update matching personal project statuses as pull requests progress, even when GitStride is closed.

GitStride connects to GitHub Projects and requires a GitHub.com account. Sign in using a device code and authorize access to your projects. No command-line tools are required. The optional pull request automation service requires separate authorization.
