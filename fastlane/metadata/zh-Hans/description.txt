GitStride 迹程让你在一个工作区中整理项目、跟进事项和查看代码审查请求。从菜单栏快速查看项目，也可以在主窗口集中处理手头工作。

• 使用看板或表格整理个人和组织的项目。
• 在「我的工作」中集中查看多个项目的待办与代码审查请求。
• 按标题、事项编号或负责人搜索，直接创建和编辑事项，无需切换到浏览器。
• 自定义字段和筛选条件；显示偏好保存在本机。
• 应用运行时，可选择接收状态和负责人变更、临近截止日期及逾期提醒。
• 可选连接独立的拉取请求自动化服务，让关联拉取请求的进展更新匹配的个人项目状态；关闭应用后仍可继续运行。

GitStride 连接 GitHub Projects，需要 GitHub.com 账号。通过设备验证码登录，并授权访问你的项目，无需安装命令行工具。可选的拉取请求自动化服务需要另行授权。

GitStride 为独立开发的应用，与 GitHub, Inc. 无关联，也未获得其背书或赞助。
